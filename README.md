# 🏃‍♂️ RUN FROM THE PRINCIPAL! 🏫💨

An endless Subway Surfers-style 3D school hallway runner game built with pure vanilla HTML5 Canvas, CSS3, and the Web Audio API.

🎮 **[Click here to Play Live!](https://adithyan15-11.github.io/run-from-the-principal/)**

---

## 🕹️ Controls

### Keyboard (Desktop)
- **Left Arrow / A**: Move Left
- **Right Arrow / D**: Move Right
- **Up Arrow / W / Space**: Jump
- **Down Arrow / S**: Slide
- **P**: Pause / Resume
- **M**: Mute / Unmute

### Touch (Mobile / Tablet)
- **Swipe Left / Right**: Change lanes
- **Swipe Up**: Jump
- **Swipe Down**: Slide
- **On-screen Buttons**: Pause, Restart, Select Character

## ⚡ Boosters & Power-ups
- 🍕 **Pizza Boost**: Invicibility speed boost that smashes right through desks and chairs!
- 🚀 **Rocket Bag**: Soar high above all corridor obstacles!
- ☕ **Coffee Magnet**: Magnetic field that pulls in all A+ Grade Stars from every lane!
- 🛡️ **Hall Pass Shield**: Protective dome that absorbs an obstacle hit!
- 😆 **Goofy Laughs**: Collecting boosters triggers hilarious custom laughing audio!

---

## ⚠️ Obstacles & Hazards
- 🪑 School Desks, Chairs & Bookstacks
- 📜 Hanging Banners & Wet Floor Signs
- 💧 **Urine Puddles**: Slipperiest hazard in the hall! Causes a 1.8s crying slip while the Principal speeds up!
- 💩 **Poop Piles**: Slide right over with loud comic sound effects!

---

## 🚨 Busted & Detention
When the Principal finally catches up to you, experience a cinematic slow-motion grab animation with custom voice dialogue (*"Poleyadi mone! Busted!!"*) followed by an official Detention Slip report card!

---

## 🚀 Built With
- **Vanilla HTML5 Canvas**: Pseudo-3D corridor projection with dynamic perspective scaling
- **Vanilla JavaScript**: Zero external dependencies, pure physics, collision and particle engines
- **Web Audio API**: Real-time sound synthesis, spatial buffers, and embedded audio fallbacks
